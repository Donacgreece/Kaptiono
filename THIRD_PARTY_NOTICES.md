# Third-Party Notices

## SCNet browser vocal separation

Kaptiono's experimental Music / Lyrics Mode uses a browser-side SCNet ONNX implementation derived from:

- SCNet in the Browser by Eli White
- https://github.com/elicwhite/scnet-web-wasm
- SCNet paper: Sparse Compression Network for Music Source Separation
- SCNet upstream project: https://github.com/starrytong/SCNet
- ONNX Runtime Web by Microsoft

The integration is used only for local, on-device vocal separation before transcription.

Refer to the upstream projects for their respective license and attribution terms.

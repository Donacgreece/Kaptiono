# Contributing to Kaptiono

Kaptiono is a source-available project focused on a stable browser and PWA caption workflow.

## Before opening an issue

Please check whether the behavior can be reproduced in the latest production release at https://kaptiono.com/.

For bugs, include:

- Browser and browser version
- Operating system
- Device model when relevant
- Video container and codec information when known
- Approximate video duration
- Selected Local or Cloud model
- Export mode when the issue involves rendering
- Expected behavior
- Actual behavior
- Reproduction steps

Do not upload private video, audio, transcripts, credentials, access tokens or other sensitive information to a public issue.

## Pull requests

Pull requests should:

- Be focused on one problem or improvement
- Preserve the privacy-first product model
- Avoid adding unnecessary runtime dependencies
- Keep mobile and desktop behavior in sync
- Preserve legal and third-party license notices
- Avoid changing the public release version unless the change is explicitly part of a release
- Include testing notes for browser-specific or media-specific changes

# Kaptiono Web Lab v0.5.0

This package is the GitHub Pages friendly web build of Kaptiono.

## Included in v0.5.0
- Improved on-page SEO copy for the homepage
- Custom domain ready metadata for `https://kaptiono.com/`
- Open Graph and Twitter sharing tags
- Social sharing thumbnail at `assets/share/kaptiono-og-1200x630.png`
- Structured data with `WebSite`, `SoftwareApplication` and `FAQPage`
- `robots.txt`, `sitemap.xml` and `llms.txt`
- Apple touch icon and PNG favicons
- Cache version bump for the new release

## Notes
Before going live on the real domain, connect `kaptiono.com` to GitHub Pages and let the DNS propagate. The meta tags already point to the final custom domain.

# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability that could expose user data, credentials, infrastructure, service configuration or other sensitive information.

Report security-sensitive issues privately to:

**info@kaptiono.com**

Include enough information to reproduce and assess the issue, but do not send private user videos, audio, transcripts or unrelated personal data.

## Scope

Relevant reports can include issues affecting:

- kaptiono.com
- The Kaptiono PWA
- Local processing and browser storage
- Cloud transcription requests
- Release and deployment integrity
- Third-party runtime loading

## Disclosure

Please allow reasonable time to investigate and deploy a correction before public disclosure.

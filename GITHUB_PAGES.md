# GitHub Pages deploy notes

1. Push all files to the repository.
2. In GitHub, open **Settings > Pages**.
3. Keep **Source = GitHub Actions**.
4. Add the custom domain `kaptiono.com` when the domain is ready.
5. In your DNS provider, point the domain to GitHub Pages and wait for propagation.
6. After the custom domain works, verify that the share preview image loads from:
   `https://kaptiono.com/assets/share/kaptiono-og-1200x630.png`
7. Use the URL inspection tool in Google Search Console after launch.
